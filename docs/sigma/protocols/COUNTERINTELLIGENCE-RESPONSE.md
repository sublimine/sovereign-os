# Counterintelligence Response Protocol

```text
INDICATOR → TRIAGE → PRESERVE → INDEPENDENCE_CHECK
→ MINIMUM_CONTAINMENT → HYPOTHESES → BLAST_RADIUS
→ INVESTIGATE → CONFIRMED|REFUTED|UNRESOLVED
→ REMEDIATE → CLEAN_REPLAY → VARIANT_TEST → MONITOR
```

No attribution or sanction at TRIAGE. Evidence access is purpose-scoped; the
implicated chain cannot appoint sole investigator. Containment revokes leases,
freezes publication and isolates compartments while maintaining operations on
clean routes. Unresolved cases retain monitoring and residual risk.
