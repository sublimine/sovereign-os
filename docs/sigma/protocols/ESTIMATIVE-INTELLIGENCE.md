# Estimative Intelligence Protocol

```text
QUESTION → RESOLUTION_RULE → REFERENCE_CLASS → HYPOTHESES
→ EVIDENCE_FREEZE → PRIOR/RANGE → UPDATE → SENSITIVITY
→ SIGNPOSTS → INDEPENDENT_REVIEW → COMMIT
→ WAIT_OUTCOME → RESOLVE → SCORE → RECALIBRATE_CLASS
```

Question includes exact target, horizon and resolution source. If no defensible
base rate exists, state it; do not invent prior. Evidence freeze prevents outcome
leak. Estimates version on material evidence and retain old distribution.
Conditional projections state condition. Scenarios never receive forecast score.

Resolution dispute is adjudicated independently. Calibration requires sufficient
sample by task class; small samples show intervals. Outcome feedback cannot edit
the frozen estimate.
