# Productos, Compresión y Diseminación

## 1. Product selection

| Necesidad | Producto |
|---|---|
| segundos/minutos | CriticalSignal/WarningNotice |
| actualización | IntelligenceUpdate |
| una pregunta | IntelligenceNote |
| realidad compleja | AllSourceAssessment |
| actor | ActorDossier |
| futuro | Estimate/Forecast |
| oportunidad | OpportunityAssessment |
| vigilancia | WatchBrief/Handover |
| decisión soberana | OmegaIntelligencePacket |

Formato deriva de decisión, tiempo y canal; no de preferencia del redactor.

## 2. Anatomy

Key judgments; exact epistemic label; what changed; evidence/counterevidence;
source independence; assumptions; UNKNOWN/gaps; alternatives/dissent;
deception/CI; implications, not decision; indicators/review; methodology;
drill-down and omissions. Un executive summary no puede ocultar un factor que
cambiaría la decisión.

## 3. Compression without loss

Raw→structured→claim→finding→judgment→product. Cada reduce almacena selection
rule, excluded refs and reason, aggregation method y hashes. Drill-down inverso
debe resolver sin depender de memoria del autor.

## 4. Dissemination decision

Audience identity, purpose, compartment, minimum fields, redactions,
watermark/version, expiry, onward-sharing, channel, approvals y revocation.
Author Σ37 no es único approver. Sensitive dissemination requiere Σ13 + policy;
external/legal effect requiere Ω21/humano.

## 5. Corrections

Product registry mantiene consumer list y acknowledgment. Retraction/correction
emite direct notification, not merely updated link. Critical prior decisions
dependientes escalan Ω2/Ω23. Revocation no destruye audit copy.
