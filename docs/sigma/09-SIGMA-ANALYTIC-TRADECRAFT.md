# Tradecraft Analítico Σ

## 1. Selección de método

El método deriva de la pregunta:

| Pregunta | Método mínimo |
|---|---|
| qué ocurrió | chronology + source/claim audit |
| quién/qué es | entity resolution |
| quién se relaciona | temporal typed network |
| cuánto | measurement/sampling/error model |
| por qué | competing DAG/mechanism/process trace |
| qué pretende/capaz | actor model + alternatives/signposts |
| qué ocurrirá | resolvable estimate + calibration |
| qué vigilar | indicators + warning thresholds |
| qué puede sorprender | boundary inversion/discontinuity |
| dónde hay oportunidad | mechanism/window/adverse-selection |

Un método no apropiado se rechaza aunque produzca narrativa plausible.

## 2. Hipótesis competidoras

Incluye null, benign error, deception y mechanism-distinct alternatives.
Predictions/forbidden observations se definen antes de mirar evidencia cuando
sea posible. La matriz pondera diagnosticidad, source quality, dependency y
observability. Ganador provisional no elimina perdedores.

## 3. Anti-groupthink

Blind analysis, evidence order randomizado, provider/method diversity,
pre-mortem, inversion, devil's advocate con discriminante, minority report y
delayed reconciliation. “Contrarian” sin mecanismo/test es ruido y se termina.

## 4. Estimación

Question/resolution/horizon, base rate, evidence likelihood, distribution,
assumptions, sensitivity, signposts, calibration class y frozen timestamp.
Forecast ≠ scenario ≠ projection ≠ simulation. Outcome resolution es por regla
predefinida; ambigüedad la adjudica instancia distinta.

## 5. Confianza

Vector: measurement quality, source independence, coverage, replication,
freshness, contradiction, method strength, sensitivity y calibration. Hard
defect impone ceiling. No promedio permite que volumen compense lineage roto.

## 6. Explainability

No se guarda chain-of-thought. Se guardan evidence matrix, DAG, calculations,
source graph, hypotheses, assumptions, alternatives, objections, sensitivity,
decision implications y reason codes reproducibles.
