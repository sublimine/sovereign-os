# Model, Tool y Reasoning Routing Σ

## 1. Provider-neutral tiers

- A: frontier synthesis/novel M3–M4/causal/deception/surprise.
- B: high-reasoning workhorse.
- C: bounded extraction/classification with validators.
- D: cheap routing/simple transformation.
- DETERMINISTIC: schemas, policy, hash, graph, math, parsing and exact diff.

Brand/subscription/API/local is adapter metadata, not institutional design.

## 2. Route selection

Minimum passing tier from task-class evals plus margin. Score: capability fit,
context fit, tool reliability, language/domain, security deployment, latency,
cost and independence value. Maximum model is not default.

## 3. Reasoning effort

Low: routing/format. Medium: bounded extraction/comparison. High: multi-source
analysis, ambiguity, source motives. Maximum: novel M4, causal identification,
deception, estimate reversal, CI, surprise and final complex fusion.

## 4. Quality escalation

Escalate before failure on negative eval margin, inability to state method,
context no longer sufficient after retrieval, unresolved schema failures,
novel domain, adversarial exposure or sensitivity. Escalation may choose better
tool/data/method rather than larger model.

## 5. Cognitive independence

Material replication varies provider/model family when available, method,
prompt charter, evidence subset/order, tool and analyst framing. Same provider
may be used only if other dimensions create independence and dependency score
records limitation.

## 6. Reputation/calibration

Metrics by exact model/version/task/language/tool profile: accuracy, Brier,
log-loss, ECE, coverage, FP/FN, hallucination, authority violations, cost,
latency and disagreement value. History influences routing, never truth.
