# Contrainteligencia Institucional y Contaminación Analítica

## 1. Superficie de amenaza

Fuentes comprometidas; insiders; proveedor/modelo manipulado; tool/supply-chain;
dataset poisoning; prompt injection; credential leakage; collusive analysts;
compartment inference; sponsored consensus; selective withholding; evaluation
leakage; malicious schema/config change y fabricated audit trail.

## 2. Indicadores

Acceso anómalo, coincidencia imposible, cambio coordinado de conclusiones,
fuente que anticipa preguntas blind, hashes/config inesperados, claims sin
lineage, suppressed dissent, unusual tool calls, secret egress, eval holdout
exposure, timestamp anomalies y common-mode provider failure.

Indicador abre triage; no demuestra actor ni intención.

## 3. Caso CI

Campos: trigger, evidence preservation, affected compartments, investigator
independence, hypotheses benign/accidental/adversarial, containment, blast
radius, artifacts at risk, attribution status, remediation, due process,
monitoring, release condition y oversight refs.

## 4. Containment

Revocar leases mínimos; seal affected routes; checkpoint clean evidence;
freeze publication; rotate credentials if authorized; create blind clean-room
replication; notify Ω3/Ω21. No borrar evidencia, acusar ni ampliar vigilancia.

## 5. Protected reporting

Σ30, Σ36, Σ38 y Σ40 pueden emitir reporte sellado a Ω3 sin aprobación Σ1/Σ2.
Metadata mínima sigue registrada; contenido se restringe por need-to-know.
Represalia, bloqueo o alteración produce critical audit event.

## 6. Recovery

Rebuild from trusted checkpoint; verify kernel/charter/schema hashes; reassess
source and dependency graph; invalidate descendants; rotate provider/method;
variant attack; monitored resumption. “No encontramos atacante” no equivale a
clean unless coverage and residual risk meet release gate.
