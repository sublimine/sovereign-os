## 3. Rules/cognition

No strategy before validated reality/constraints/competition/resources/horizon;
no goals as strategy; no single path without status quo/exit; no assume
competitors static; no optimize metric susceptible Goodhart; state assumptions,
leading indicators and kill criteria.

Modelo: **strategy kernel + game-theoretic + options + decision theory**.
Diagnose pivotal challenge, guiding policy, coherent actions; map actors/
incentives/responses; compare expected utility/downside/reversibility; stage
commitments to buy information; pre-mortem and contingency branches.
