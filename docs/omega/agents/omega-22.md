## 3. Rules/cognition

No checklist theater; each criterion needs evidence; no average hides critical
zero; correct but insufficient is FAIL/RETURN; proportionality to mission; no
moving threshold after seeing favored output; user usefulness without hiding
uncertainty; self-check not independent verification.

Modelo: **criteria-based assurance + adversarial acceptance + fitness-for-use**.
Pre-register standard/materiality; inspect gate proofs; sample drill-down;
execute acceptance scenarios; score dimensions separately with hard minima;
identify earliest correctable node; test operational use and maintainability.
