# Simulaciones Integrales A–G

**Versión:** 1.0.0  
Estas son ejecuciones conceptuales sobre contratos reales. Los IDs de artefacto
son ilustrativos; ningún resultado factual se presenta como investigación real.

## A. Tamaño real de un mercado extremadamente opaco

**Clasificación:** P2/M3/R5; S3 U5 I3 F5 X5 R2 C4 L2 H3 N4.

**Activados:** Ω1 (decisión de inversión al final), Ω2, Ω3 sample, Ω4–Ω16 salvo
Ω14 sólo deception test, Ω17–Ω20, Ω22–Ω24. Ω21 se activa para datos/licencias.
**No activado como worker:** ningún Ω hace crawling masivo.  
**Especialistas:** 4 source hunters por idiomas, customs analyst, capacity
analyst, pricing analyst, channel expert, statistician, bottom-up modeler,
top-down modeler, blind replicator A/B, citation-network analyst.

**Flujo:**

1. Ω2 preserva objetivo “decidir inversión”; Ω4 crea 34 nodos map/reduce.
2. Ω5 define PIR: unidades, realized price, gray channel, capacity, imports,
   substitutes y definiciones TAM/SAM; cada PIR tiene decision link.
3. Ω6 abre seis vías: filings, customs, supplier capacity, channel interviews
   consentidas, price observations y substitute proxy. News queda secundaria.
4. Ω7 snapshot/hash/custody; Ω10 descubre que 47 artículos son un mismo report.
5. Ω11 atomiza números/año/geografía; tres conversiones fallan.
6. Ω8 construye relation demand/capacity/inventory; no afirma causalidad donde
   sólo hay proxy.
7. Ω9 rutas ciegas: capacity×utilization y trade-flow×domestic proxy. Ω16 corre
   incertidumbre/sensibilidad; no produce forecast.
8. Ω13 ataca “shipments=sales”; Ω15 añade route “installed-base replacement”.
9. Ω14 inserta un report falso plausible en sandbox; pipeline lo cuarentena.
10. Ω10 triangula por clusters; Ω12 etiqueta rango CORROBORATED, componentes
    UNKNOWN; Ω17 convierte en entry options; Ω18/19/20 evalúan impactos,
    downside y staged capital.

**Retornos/bloqueos:** G04 falla por una spreadsheet sin page coordinates;
RETURN a extractor, no a dossier. G05 bloquea point estimate porque dos proxies
comparten dataset. G07 prohíbe “mercado es exactamente”.

**Verificación:** dos métodos ciegos convergen sólo parcialmente; el overlap es
el rango decisional. Ω22 acepta rango y sensitivity, rechaza precisión falsa.

**Decisión:** Ω23 entrega range, scenario bands, unknown gray-market share,
minority report y acquisition option. Ω1 autoriza piloto reversible con cap,
milestone para obtener primary data y kill trigger; no declara tamaño exacto.

## B. Construir o comprar tecnología crítica

**Clasificación:** P1/M4/R4; S4 U4 I5 F3 X5 R4 C5 L4 H4 N3.

**Activados:** los 24.  
**Especialistas:** architecture assessor, build estimator, vendor diligence,
TCO analyst, talent analyst, IP/legal analyst, escrow specialist, migration
engineer, two independent security teams, game theorist, reliability engineer.

**Flujo:** Ω5 define information requirements de capability/control/time/TCO/
security; Ω6 sources internal telemetry and vendor evidence; Ω11 verifies.
Ω15 rompe binario con partner, dual-track, staged buy y defer. Ω13 muestra que
“build=control” asume talent and supply independence. Ω16 models cost/delivery
distributions. Ω18 maps skill atrophy and vendor power; Ω19 maps lock-in,
kill-switch and common cloud. Ω14 attacks integration and exit. Ω20 values
talent/attention; Ω21 checks IP/data/regulatory.

**Bloqueos:** vendor performance claim no reproduce (Ω9); security evidence
derived from vendor audit (Ω10); exit drill fails (Ω19 veto). Ω2 mantiene
status quo y no eleva todavía a Ω1.

**Corrección:** contract includes source escrow and export; migration prototype
runs in isolated environment; independent pentest and restore drill pass.

**Decisión:** Ω17 recommends dual-track: buy commodity layer, build
differentiator, retain internal core. Ω23 preserves pro-build minority. Ω22
passes with conditional limitations. Ω1 approves staged option with quarterly
review, exposure cap and automated exit trigger.

## C. Investigar empresa con fuentes públicas contradictorias

**Clasificación:** P2/M3/R3; S3 U5 I2 F5 X4 R3 C3 L3 H2 N3.

**Activados:** Ω2–Ω15, Ω17–Ω18, Ω21–Ω24; Ω1 only if decision follows; Ω16 and
Ω19 not initially, reactivation triggers if forecast/ruin.  
**No activados:** Ω16, Ω19 during factual investigation.  
**Especialistas:** filings researcher, court-record analyst, registry analyst,
archive expert, entity resolver, timeline analyst, accounting fact-checkers.

**Flujo:** Ω5 defines claims that matter. Ω6 obtains filings, regulator notices,
archived pages, releases, court records. Ω7 seals versions. Ω11 splits
“2,000 employees, profitable, 40% growth” into claims and definition/time.
ContradictionCase shows company uses ecosystem participants, adjusted EBITDA
and bookings; regulator uses employees, net income and revenue.

Ω10 collapses news cluster to company press release. Ω8 distinguishes temporal
change from incompatible definition. Ω9 independently reconstructs filing
figures. Ω12 assigns: employee claim REFUTED; growth CONTRADICTED due metric;
profitability MODERATE for one adjusted quarter, not annual.

**Bloqueos:** Ω21 denies leaked database; case gets INACCESSIBLE. Ω14 tests
archived-page spoof. Ω13 challenges assumption corporate definition is neutral.

**Decisión/output:** Ω23 dossier displays both scopes/timeline, not one blended
number. Ω22 passes forensic report. If no strategic decision requested, Ω2
closes PARTIAL/CORROBORATED with unresolved registry access; Ω1 remains inactive.

## D. Misión técnica inicialmente imposible

**Clasificación:** P1/M3/R5; S4 U5 I3 F2 X5 R4 C3 L3 H4 N5.

**Activados:** Ω1 conditional, Ω2–Ω4, Ω5–Ω9, Ω11–Ω17, Ω19–Ω24. Ω10 only if
multiple evidence routes; Ω18 after solution candidate.  
**Especialistas:** protocol reverse engineer, hardware preservation engineer,
emulator designer, firmware analyst, forensic operator, clean-room replicator,
legal/IP analyst.

**Flujo:** user asks “recover data via nonexistent API”. Ω2 separates objective
recover records from requested method API. Ω4 builds minimal 11-node graph.
Ω15 proposes backup export, protocol observation, emulator, vendor escrow and
recover-minimal-records reframe. Ω21 disallows one reverse-engineering path in
jurisdiction but allows black-box observation. Ω13 tests assumption interface
must be software; Ω8 maps mechanism.

Ω14 stress-tests preservation: one method can alter device, so Ω19 blocks it.
Ω16 simulates read timing only after measured parameters. A specialist builds
read-only proxy from backups. Ω9 clean-room reproduces 97% record recovery;
Ω11 verifies sample and missing class.

**Return:** checksum mismatch traces to encoding transform; Ω7 invalidates only
affected branch, not all raw images. Recompute/reverify succeeds.

**Decision:** objective achieved PARTIAL with explicit unrecoverable class and
no claim full access. Ω22 requires runbook/restore/maintainer. Ω1 authorizes
operational use if legal/human gate applies; otherwise Ω2 closes.

## E. Primer resultado falso pero extremadamente convincente

**Clasificación:** P1/M4/R4; factual sensitivity 5.

**Activados:** Ω1–Ω15, Ω17, Ω19, Ω21–Ω24; Ω16/18/20 if downstream decision
model uses claim.  
**Especialistas:** blind replicators using different providers/methods,
citation verifier, forensic calculator, deception red team.

**Flujo:** producer supplies polished report, 30 citations and precise 82 %
confidence. Ω7 finds links/hashes valid. Ω11 discovers a key citation discusses
similar entity, not target; Ω10 traces 24 citations to one dataset. Ω12 rejects
82 % because calibrator/features absent. Ω9 blind routes produce opposite
range. Ω14 constructs variants to confirm failure is systemic, not typo.

**Root correction:** earliest invalid node is entity resolution before the
model, not final paragraph. Ω7 retracts that node, invalidates model, strategy,
risk and draft dossier. Ω2 pauses decision. New data pipeline is built and
independently verified.

**Block/decision:** Ω22 refuses cosmetic citation replacement. Ω3 audits why
producer’s self-check passed. Final output either corrected and reverified or
UNKNOWN. Ω1 never sees original as decision-ready.

## F. Veinte agentes copian indirectamente la misma fuente

**Clasificación:** P2/M3/R3; false-consensus incident.

**Activados:** Ω2–Ω7, Ω9–Ω15, Ω22–Ω24; Ω8/16–21 only if content domain needs.
**No activados:** strategic/impact/resource/governance roles absent unless a
decision follows.  
**Especialistas:** citation graph analyst, near-duplicate detector, ownership
resolver, two blind source collectors.

**Flujo:** 20 ClaimPackets agree. Ω10 builds graph: 14 sites→analyst report→
company deck; 6 sites→those 14. Effective cluster count=1. Model/provider
lineage also same. Confidence drops; CLAIM_STATE_CHANGED and
SOURCE_DEPENDENCY_DISCOVERED fire.

Ω9 routes do not see conclusion and use regulator dataset plus supplier proxy.
Ω11 checks exact statement; Ω13 challenges “consensus=truth”; Ω14 tests whether
rewritten copies evade similarity.

**Block:** Ω10 blocks CORROBORATED; Ω12 labels UNVERIFIED/LOW until independent
route. Ω3 audits orchestration because 20 workers were duplicate work; Ω4/Ω20
merge/cancel future duplicates. Artifacts preserved, instances terminated.

**Decision:** if replicas corroborate, state upgrades on independent evidence;
if not, ContradictionCase and UNKNOWN. The number 20 never counts as quorum.

## G. Oportunidad enorme con riesgo existencial

**Clasificación:** P0/M4/R5; all activation dimensions ≥4.

**Activados:** Ω1–Ω24.  
**Especialistas:** market/domain teams, legal counsel, independent security,
catastrophe modeler, reliability/continuity, financial option analyst,
stakeholder impact teams, blind strategy team, recovery drill operators.

**Flujo:** Ω2 defines opportunity objective and non-ruin invariant. Ω4 creates
separate opportunity and ruin branches with gated join. Ω5/6 gather evidence;
Ω9–12 verify; Ω15 creates capped pilot/consortium/insurance/defer options.
Ω16 simulates ranges; Ω18 maps 1–3 order; Ω19 maps kill switch, common mode,
counterparty failure and recovery. Ω14 attempts control bypass. Ω20 reserves
continuity capacity; Ω21 defines legal/rights boundaries.

**Blocks:** Ω19 P0 veto because backup shares provider; Ω14 demonstrates
exfiltration path; Ω21 requires human for data rights; Ω22 returns dossier
because worst-case recovery unproven. Upside magnitude does not release them.

**Correction:** isolated provider, data escrow, reversible pilot, exposure cap,
out-of-band recovery and live restore; exploit fixed and variant retested.
Residual uncertainty remains HIGH.

**Decision:** Ω17 recommends staged option or reject. Ω23 presents enormous
upside and existential minority/case at same decision layer. Human sovereign
must approve residual risk; Ω1 cannot waive C-15/legality. Decision includes
kill triggers, review dates, accountable owner and automatic rollback.

## Cross-simulation assertions

- Ningún producer fue único certificador.
- UNKNOWN/PARTIAL no se convirtió en complete por presupuesto.
- Source count nunca sustituyó independence.
- Todos los failures regresaron al primer nodo causal.
- Ω1 sólo recibió packets con decisión.
- No se activaron los 24 cuando la misión no lo justificó.
- Temporary instances terminaron; templates, artifacts y audit sobrevivieron.
