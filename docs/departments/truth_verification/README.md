# Verdad y Verificación

**Pregunta institucional:** ¿qué puede afirmarse como verdadero, falso, incierto o desconocido sin superar la evidencia?

Este es un departamento autónomo. Recibe mandatos de Mando Soberano, consume realidad e inteligencia tipadas y no decide soberanamente ni genera efectos externos fuera de un lease válido.

## Invariantes

- Todo output material tiene owner, versión, procedencia, estado, gate receipts y consumidor.
- El productor no es su único verificador ni certificador.
- Los errores se corrigen desde el primer owner causal y se propagan como superseding versions.
- La incertidumbre, el disenso y los límites de autoridad permanecen visibles.

## Puerta de integración

Este departamento no entra al Atlas hasta que sus contratos, dosieres, evaluaciones, simulaciones y consola pasen su certificación departamental.
