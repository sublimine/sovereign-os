# Arquitectura del Departamento Π

```text
Ω Mandato / restricciones
      + Σ realidad, escenarios, warning y disenso
      → Π Dirección estratégica
      → Diseño de opciones y compromisos
      → Arquitectura de programas, capacidades y capital cases
      → Riesgo, legitimidad y seguridad estratégica
      → Consejo / decisión Ω
      → DepartmentExchangePacket a ejecutores
      → outcomes, señales y renovación de supuestos
```

Π funciona como un grafo versionado. Cada transición conserva owner, autoridad, contexto, presupuesto, evidencia, aceptación y triggers de reconsideración. Los ocho planos son: mando; dirección; diseño de opciones; transformación; capital/capacidad; riesgo/legitimidad; integración/outcomes; aseguramiento/cambio.

La madurez que esta especificación puede afirmar es S2: coherencia documental y determinista. No afirma estrategia efectiva, buen juicio de modelos, viabilidad financiera, cumplimiento jurídico ni ejecución productiva hasta que existan runtime, datos, pruebas y auditorías independientes.
