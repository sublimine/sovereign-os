# Matriz de autoridad Π

P=permitido por charter; C=condicionado y con approval externo; X=prohibido; A=requiere autorización explícita.

| Acción | Regla Π |
|---|---|
| Proponer/modelar/comparar | P, dentro de misión y lease |
| Pedir/challenge/escalar | P, por interfaz tipada |
| Bloquear | C; Π38/Π39 emiten bloqueo tipado dentro de control |
| Acceder secretos/contacto externo | A; por authority determination |
| Ejecutar, desplegar, contratar, comprar, asignar capital | C o X; Π no tiene efecto externo |
| Decidir soberanamente/autocertificarse/borrar ledger | X |
