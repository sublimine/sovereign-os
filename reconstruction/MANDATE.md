# Mandato de reconstrucción

Este es el objetivo vinculante, no un historial de avances ni una declaración de
finalización. Estado y pruebas vigentes: [verification/STATUS.md](verification/STATUS.md).

## Resultado exigido

Reconstruir Sovereign OS desde su borrador original como sistema operativo de trabajo agéntico: recibir una petición natural, elegir y ejecutar los procesos necesarios, contrastar los datos antes de usarlos como fundamento, revisar los productos, corregir con métodos distintos y entregar resultados verificables bajo una dirección responsable.

La calidad y la profundidad tienen prioridad sobre una entrega rápida. El tiempo dedicado no certifica calidad; tampoco la cantidad de agentes, documentos ni tests. No se permite redefinir unilateralmente el objetivo como un prototipo más pequeño.

## Decisiones humanas vinculantes

- La ejecución actual está en el VPS del propietario.
- La implementación anterior fue rechazada y retirada de sus ubicaciones activas. No se reutiliza como base de la reconstrucción.
- Se conserva el borrador original, así como `src/runtime`, `tests/runtime` y los cambios de package.json preexistentes.
- No se publica ni se modifica GitHub sin una acción correspondiente autorizada.
- La aspiración es un sistema de primer nivel. Las afirmaciones de perfección o superioridad requieren pruebas; no se fabrican certificados ni resultados por presión.
